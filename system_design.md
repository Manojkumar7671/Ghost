# System Design
## 1. Core Visual Dashboard Layout
* High-level metrics counter showing Total Bookmarks, Favorite Links, Unread Reading List, and Custom Collections
* Dynamic View Options: Toggle between Grid Cards, Compact List view, and KanBan Board view
* Dark / Light Glassmorphic Theme: Dark mode by default with glowing accent badges, fluid micro-interactions, and smooth transitions
## 2. Smart Bookmark Management
* One-Click Add & Auto-Metadata Extraction
* Categorization & Multi-Tagging
* Favorite & Pinning
* Archiving & Reading State
## 3. Search & Filtering System
* Real-Time Instant Search
* Filter Chips
* Broken Link Detection & Status Check
## 4. Productivity & Sharing Features
* Browser Extension / Quick Import & Export
* Public & Private Share Links
* Notes & Annotations
## Proposed Tech Stack
* Frontend: HTML5, CSS3, Modern Vanilla JS / Vite
* Backend: Node.js + Express REST API
* Storage: SQLite / JSON DB
